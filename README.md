# 상품 검수 기준 가이드

버킷(오늘의집) 상품 등록 검수 기준을 정리한 가이드. 인증/규제 대상, 판매 제한, 이미지 정책 위반, 라이선스 등 카테고리별 승인/거절 기준을 담고 있음.

## 실제 편집은 여기서

이 가이드는 Claude 아티팩트에서 직접 편집·저장됨:
https://claude.ai/code/artifact/3d2a28c2-5655-4ed3-a069-44a264a9041d

이 저장소(`index.html`)는 그 아티팩트 내용을 주기적으로 자동 동기화하는 미러/히스토리용. 즉 이 repo의 파일을 직접 고쳐도 아티팩트에는 반영되지 않음 — 항상 위 링크에서 편집할 것.

## 구조

- `index.html` — 자체완결 HTML (사이드바 카테고리 + 항목 카드, 검색, 편집/저장 UI 포함)
