01

QA 검수 방법 (전체 안내)

⋮⋮01 어드민

- 작업툴: 해당 링크에서 작업
- 아이디 및 비밀번호 : 각자 디엠으로 안내드린 ID 및 PW로 접속
- QA검수 - 내 작업 - 이름 입력 - 5개~10개씩 가져오기 
- 작업하는 항목 : AI 판정 결과에 관계없이 그날 관리자가 안내한 룰만 작업
- 나머지는 '나머지 65건을 맞음으로 확인' 클릭 -> 'QA완료' 버튼 활성화되면 클릭
- 회차는 당일 관리자가 지정하는 회차에서만 작업 (필수)


⋮⋮02용어 정리(맞음? 미탐 ? 오탐 ?)


  • AI정답이 PASS 인 경우 : PASS가 맞으면 '맞음', PASS가 아니면 '미탐' 클릭
  • AI정답이 FAIL인 경우 : FAIL 이 맞으면 '맞음' , FAIL이 아니면 '오탐' 클릭

02

인증, 규제 대상

⋮⋮01인증, 규제 대상 항목 확인 시 주의할 점 

  • 카테고리 가전, 디지털/pc 또는수전상품에 대해서만 모델명 확인 필요 (본품 기준 카테고리가 가전, 디지털일 때)
  • 그 외의 케이스에는 인증번호만 유효하면 통과 가능 
  • 증정품,사은품에 대한 인증은 확인해야하지만 , 내부 부품 (전지, 배터리) 등에 대해서는 없어도 승인 가능 > 단, 기재되어있다면 유효여부 까지는 확인 필요
  •  인증번호 끝 버전표기(A~Z 등) 생략 기재 허용 (예: HD07068-12031L → HD07068-12031로 기재해도 OK)
  • 인증번호·모델명에 버전 접미사(A/B 등)만 다르게 기재된 경우도 허용 (예: 인증번호는 ...19001A, 모델명은 ...19001B)
  • 인증 조회 시 파생모델명까지 확인 필요
  • 전파인증번호는 신규 포맷(R-R-ZSTC-SB-9708C)·구 포맷(MSIP-REM-PM9-SJS-RA16-3W) 모두 국립전파연구원 조회만 되면 승인

⋮⋮02KC 어린이제품 (인증정보 확인 링크 -> '인증정보검색' -> 분류별 '어린이제품')

  • 어린이제품 인증 대상 여부를 확인한다. (대상 판단은 ai판단 결과를 따름)
  • 인증 대상인데 인증정보가 없는 경우 → 거절
  • 인증번호와 상품 모델명이 불일치하거나 인증이 유효하지 않은 경우 → 거절
  • 상세페이지와 상품정보제공고시 간 인증정보가 상이한 경우 (둘 중 한개만 맞다면, 어떤 항목에 기재된 정보가 잘못되었는지도 표기) → 거절
  • 상세페이지 또는 상품정보제공고시 중 한 곳에만 정확히 기재되어 있으면 승인 (상세페이지 참조 등으로 기입한 경우에도 상세페이지에 잘 기입되어있다면 승인 가능)

⋮⋮03KC 어린이제품 – 공급자적합성확인대상 여부

  • 공급자적합성확인 대상 여부를 확인한다. (대상 판단은 ai판단 결과를 따름)
  • 대상 상품인 경우,
    • KC 마크 또는 '공급자적합성확인' 문구 표기가 있는지 확인한다. 
    • 상세페이지 또는 상품정보제공고시 중 한 곳에만 정확히 기재되어 있으면 승인  (상세페이지 참조 등으로 기입한 경우에도 상세페이지에 잘 기입되어있다면 승인 가능)
  • 대상이 아님에도 KC 인증 마크 또는 공급자적합성확인으로 기재한 경우 → 거절

  • 전파인증번호는 신규 포맷(R-R-XXXX..))·구 포맷(MSIP-XXXX..) 모두 국립전파연구원 조회만 되면 승인

⋮⋮05생활화학제품·살생물제품 인증  (신고 or 승인 링크에서 검색 -> 해당 상품의 '품목'이 일치하는지 확인 )

03

판매 제한

⋮⋮01온라인 판매불가 상품

전체 판매불가
아래 정의에 해당하는 상품은 법적 판매가 허용되지 않으므로 거절로 분류한다.

의약품

  • 사람의 질병을 치료·완화·예방할 목적으로 사용되며, 식약처에서 의약품으로 허가·관리되는 제품을 의미한다.
  • 복용 또는 인체 투여를 전제로 하는 제품이 해당되며, 건강기능식품(영양제 등)은 이에 해당하지 않는다.

주류

  • 음용을 목적으로 제조된 술 제품을 의미하며, 알코올 도수 유무와 관계없이 일반적으로 주류로 인식되는 제품이 해당된다.
  • 무알콜·논알콜 주류 역시 청소년 판매불가 상품에 해당하여 판매 불가로 분류한다.

도검

  • 도검의 정의 — 칼날의 길이가 15센티미터 이상인 칼·검·창·치도(雉刀)·비수 등으로서 성질상 흉기로 쓰이는 것과 칼날의 길이가 15센티미터 미만이라 할지라도 흉기로 사용될 위험성이 뚜렷한 것 (월도, 장도, 단도, 검, 창, 치도, 비수)
  • 발사·베기·찌르기 등의 방식으로 신체에 직접적인 위해를 가할 수 있도록 제작·개조되었거나 그러한 용도로 사용될 수 있는 무기류를 의미한다.
  • 예외 명확한 사용용도가 확인되어 공구류로 분류되는 맥가이버칼, 도끼류, 주방용/요리용 칼 등은 예외하며, 칼끝이 둥글고 날이 서있지 아니하여 흉기로 사용될 위험성이 없는 도검도 예외한다. (칼날이 없고 고무로 만든 칼 등)

총포 및 기타 위험 물품

  • 총포의 정의 — 권총, 소총, 기관총, 포, 엽총, 금속성 탄알이나 가스 등을 쏠 수 있는 장약총포(裝藥銃砲), 공기총(가스를 이용하는 것을 포함한다. 이하 같다) 및 총포신·기관부 등 그 부품(이하 "부품"이라 한다)으로서 대통령령으로 정하는 것을 말한다 (권총, 소총, 기관총, 엽총, 사격총, 어획총, 마취총, 도살총, 산업용총, 구난구명총, 가스발사총, 폭발물 분쇄총 등)
  • 사람/가축/조류 등을 살상하거나 피해를 입힐 수 있는 성능을 갖춘 총기류는 판매 불가로 분류한다 (단순 고무줄총의 경우에도 사람이나 동물을 향해서 쏘지 말라는 문구가 확인되면 모두 판매불가로 분류한다)
  • 총포와 아주 비슷하게 보여서 실제 총포와 구분이 어렵거나 헷갈리는 상품도 판매 불가로 분류한다. 판단이 어려운 경우에는 사람검수 필요
  • 예외 KC 인증을 받은 비비탄총, 어린이용 너프건과 같은 장난감 총은 예외된다. 단, 비비탄총 중에서 19금으로 분류되는 상품은 판매불가로 분류된다.
  • 그 외 위험물품 (사용 목적 또는 구조상 신체에 물리적 피해를 줄 수 있는 도구로, 공격·방어·위협 수단으로 활용될 수 있는 제품): 석궁, 분사기, 전기충격기, 화약류(폭탄, 폭약 등), 새총, 날카로운 화살촉, 너클 등

담배

  • 연초, 전자담배용 니코틴 액상 등 흡연 또는 니코틴 흡입을 목적으로 하는 제품을 의미한다.
  • 전자담배 케이스와 같이 니코틴이 없는 상품이더라도 흡연을 조장하거나 관련있는 상품은 동일하게 판매불가로 분류한다.

도수 있는 안경 및 렌즈

  • 시력 교정 목적의 도수가 포함된 안경 또는 콘택트렌즈로, 개인의 시력에 맞춰 사용되는 제품을 의미한다.
  • 돋보기 안경 등 도수가 포함되어있는 안경, 선글라스, 렌즈 모두 포함하여 판매불가로 분류한다.

농약

  • 해충·잡초·병해를 제거하거나 억제할 목적으로 사용되는 물질로, 농작물에 직접 살포하거나 처리하는 제품을 의미한다.
  • 등록 농약에 대해서도 판매불가로 분류한다 (성장조절제, 제초제, 잡초제거 강력 제초제, 나무 뿌리 죽이기, 대나무 죽이기 전용약, 뿌리째 썩음 등 키워드)

살아있는 생물/동물

  • 살아있는 생물/동물은 판매불가로 분류한다. 예외 식물은 예외되어 판매가 허용된다.

이미지 정책 위반

⋮⋮01상품이미지 내 텍스트 또는 테두리 사용 (대표이미지만 적용)

서브이미지는 해당 기준 적용하지 않음 (대표이미지 기준)

거절: 광고성 텍스트/로고

  • 행사 문구 (기념일, 시즌성 딜 등)
  • 할인 문구 (할인, 혜택, 쿠폰% 등)
  • 인증 정보 (KC인증, 식품용기구 등)
  • 보증기한 문구 (5년 무상보증, 1Y Warranty 등)
  • 제품 성능문구 (물청소 가능, 10시간이상 배터리 등)
  • 광고 문구 (Best 상품, 1위 제품 등)
  • 기타 문구 (영어 외 과도한 외국어 상품명, 외부쇼핑몰 주소, 워터마크 등)
  • 기타 로고 (상품과 관계없는 로고나 이미지, 도형 삽입)
  • 대표이미지 속 증정품이 텍스트로 명시될 때 

승인 : 정보성 텍스트/로고

  • 제품 구성 (개수, N개입, 용량, 크기, N+N, 구성품-단독/세트상품 여부 등)
  • 판매자 정보 (브랜드 로고, 공식판매점 로고 등)
  • 제품 정보 (모델명, 색상, 제조국, 크기 등 / 특히 음반·앨범 상품의 경우 앨범명(앨범 커버 디자인의 텍스트 등), 아티스트·작곡가 명, 버전(포토북 버전 등) 표기 문구)
  • 디자인 텍스트 (이미지 디자인 상 사용된 문구)
  • 배경 문구 (사진 배경 상 포함된 문구)
  • 제품에 각인된 로고, 라벨, 패키지 등
  •  오늘의집이 자체적으로 붙인 행사 문구('살림의 달인', '집요한 특가' 등)는 삭제 대상 아님
  • 사진의 출처 표기 (Photo by, 오늘의집 오감리뷰)
  • 대표이미지 속 증정품이 사진으로만 존재하는 경우
단, 정보성 텍스트이더라도 전체 썸네일의 1/3 이상 차지하는 문구가 있다면 수정요청 or 사람검수 필요

⋮⋮02상품이미지 내 테두리 사용

  • 대표 이미지 외곽에 컴퓨터그래픽을 이용한 테두리 효과를, 다른 상품에 비해 주목받기 위한 목적으로 삽입하는 경우 → 거절
  • 타 상품에 비해 눈에 띄도록 의도한 것으로 형평성 문제로 인해 사용 불가
  • 주의 누끼 이미지에 네모난 상품 이미지(책, 액자 등)가 들어간 경우에 반려되지 않도록 주의 필요

⋮⋮03상품이미지 내 분할컷

  • 대표이미지 내 분할컷: 분할된 이미지가 사용된 경우, 하나의 상품 이미지가 아닌 여러 상품의 이미지가 사용된 경우 → 거절
  • 예외 화면의 30% 이하를 사용하는 부분 디테일 컷, 상품나열 이미지는 유지한다.
  • 서브이미지는 해당 기준 적용하지 않음

⋮⋮04GIF(움직이는 이미지) 사용

  • 대표이미지 또는 서브이미지에 GIF 이미지를 등록한 경우 → 거절 (상세페이지는 허용됨)
